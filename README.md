## 计算机系统

### 知识架构总览

这张图按**抽象层次与主要依赖关系**组织计算机系统知识。箭头不表示程序执行时必须依次经过的步骤；编译工具与网络等主题会跨越不同层级。

```mermaid
flowchart BT
    L0["① 数字逻辑与电路<br/>晶体管 · 逻辑门 · 时序电路"]
    L1["② 计算机组成与体系结构<br/>CPU · 寄存器 · ALU · Cache<br/>主存 · 总线 · 存储设备<br/>指令集 ISA · 机器指令"]
    L2["③ 操作系统<br/>进程与线程 · CPU 调度<br/>虚拟内存 · 文件系统<br/>设备驱动 · 网络协议栈"]
    L3["④ 用户态程序与运行时<br/>原生可执行程序 · 运行库<br/>CPython · JVM · 程序运行环境"]
    L4["⑤ 应用软件与数据系统<br/>应用程序 · Web 服务<br/>数据库管理系统 · 数据处理系统"]
    L5["⑥ 分布式系统<br/>多机通信 · 分布式存储<br/>一致性 · 容错 · 云计算"]

    L0 --> L1
    L1 --> L2
    L2 --> L3
    L3 --> L4
    L4 --> L5

    T["编程语言与编译工具<br/>C / Python · 编译器 · 汇编器 · 链接器"]
    T -.->|"产生或执行程序"| L3
    L3 -.->|"用户态机器指令也由 CPU 直接执行"| L1
```

其中，分布式系统是在多个计算机系统之上构建的协作机制，不是每台计算机都必须经过的一层；网络涉及硬件、操作系统和应用等多个层次。这是一张用于整理知识的概念图，不是严格的软硬件执行栈。

## 阅读方式

在 GitHub 中打开 [文章 Markdown](systems/how-python-runs.md) 阅读正文。文中的流程图使用 Mermaid：它是可编辑的图表描述，GitHub 支持把相应代码块渲染成流程图。在本地阅读时，需要支持 Mermaid 的 Markdown 阅读器；普通文本编辑器会显示图表源码。

## 内容边界

文章说明适用的实现与环境，不把某个工具版本的表现当作所有平台的规定。实验记录只反映列明环境中实际执行过的检查，不冒充用户本人电脑上的结果。
