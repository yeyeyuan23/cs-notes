# 计算机系统学习笔记

从具体问题出发，整理计算机系统的基础原理、可复现实验与参考资料。

## 知识地图

![计算机系统：单机层级与跨层网络连接](assets/computer-systems-atlas.svg)

这张图展示的是**系统抽象关系**，不是 CPU 执行一段程序时必须依次经过的路径。两座山分别代表一台计算机，中间的三组连线强调：网络通信同时涉及应用协议、操作系统中的网络栈，以及网卡和物理链路。图中的概念也不代表每个领域都必须写一篇笔记。

| 区域 | 核心内容 |
| --- | --- |
| **硬件基础** | 数字逻辑、电路、存储与 I/O 设备 |
| **体系结构** | CPU、机器指令、ISA、寄存器和缓存 |
| **操作系统** | 进程、线程、调度、虚拟内存、文件系统、设备驱动和网络栈 |
| **用户态程序** | 原生程序、标准库与可选的语言运行时（如 CPython / JVM） |
| **应用层** | Web 服务、应用程序、数据库管理系统等 |
| **计算机网络（跨层）** | HTTP / gRPC；TCP / IP；以太网 / Wi-Fi |
| **关联领域** | 编译器与工具链、数据库原理、分布式系统、安全等；它们不构成单机必经的层级 |

普通用户态机器指令直接由 CPU 执行，操作系统并不逐条转发或解释。图中的网络连线是通信机制的抽象对应关系，不表示协议只存在于某一个软件层，也不表示每个应用都必须使用独立的语言运行时。
